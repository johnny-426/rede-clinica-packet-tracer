# Rede de uma clínica fictícia no Cisco Packet Tracer

Laboratório guiado de redes IPv4. Um roteador conecta a recepção e a triagem ao servidor que hospeda a página de teste da agenda e o serviço DNS.

## Como testar

1. Baixe [rede-clinica.pkt](./rede-clinica.pkt) e abra o arquivo no Cisco Packet Tracer.
2. No **PC0** (recepção), abra **Desktop > Web Browser** e acesse `http://192.168.20.10`.
3. No **PC1** (triagem), abra o navegador e acesse `http://agenda.clinica.test`. Os dois endereços abrem a mesma página.
